Build a complete, modern, premium website for **DikvoraX**, a software and technology services company.

## Tech Stack — Strict

Use ONLY:

* React
* Vite
* JavaScript
* JSX
* Material UI (MUI)

**No TypeScript.**

**This is a frontend-only project. Do NOT create or implement any backend.**

Do not add:

* Node.js backend
* Express
* Spring Boot
* Database
* REST API
* API endpoints
* Authentication
* Backend form submission
* Server-side code

The contact form should work entirely on the frontend with validation and a success state. Structure the code cleanly so a real API could be connected later, but do not implement one.

# Design Direction

Make the website look like a **real modern software agency**, not a generic portfolio template.

Design characteristics:

* Premium
* Modern
* Minimal
* Technology-focused
* Professional
* Startup-friendly
* Strong typography
* Excellent whitespace
* Rounded cards
* Subtle shadows
* Smooth hover effects
* Subtle animations
* Responsive on all screen sizes

Use Material UI's theme system consistently.

Use a sophisticated dark/light technology aesthetic. Prefer a restrained color palette with one strong accent color.

Avoid:

* Excessive gradients
* Excessive animations
* Stock photos
* Generic corporate imagery
* Huge walls of text
* Too many colors
* Overly complicated UI

---

# UX Requirements

* Desktop

* Mobile

* Buttons work
